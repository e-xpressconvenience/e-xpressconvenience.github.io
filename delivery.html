Important production layer

This page is the front-end template. To make rider pop-ups genuinely live across different phones, Express Convenience will need a secure backend with rider accounts, a database, real-time events/push notifications, order locking, maps/routing and location/privacy controls. Those services cannot be safely implemented with GitHub Pages alone.
